# 🏋️ FitLog — Workout Library

**Train with intent. Log every set.**

FitLog is a modern workout library and fitness planning web application designed to help users explore exercises, view detailed workout information, and organize exercises into their daily workout plan.

The application provides a focused dark-themed interface with a collection of exercises covering major muscle groups, including chest, back, legs, shoulders, arms, core, and full-body movements.

🔗 **Live Demo:** https://fit-log-project-three.vercel.app/

---

## ✨ Features

### 1. 🏋️ Workout Library

Browse a curated collection of exercises with useful information such as:

* Exercise name
* Target muscle groups
* Required equipment
* Difficulty level
* Estimated duration
* Estimated calories burned
* Sets and repetitions
* Exercise rating

---

### 2. 📋 Today's Workout Plan

Users can select exercises from the workout library and organize them into their current workout plan.

This makes it easier to decide what to train without having to search through the entire exercise library every time.

---

### 3. 🔎 Exercise Details

Each exercise has its own detailed view where users can explore the exercise information before adding it to their workout plan.

The dynamic exercise pages make the application easier to scale as more exercises are added.

---

### 4. 💾 Saved Workout Management

Users can manage exercises within their personal workout workflow by adding and removing exercises from their selected lists.

The application also uses client-side state management to keep the workout experience interactive and responsive.

---

### 5. 📱 Responsive & Modern UI

FitLog is designed with a modern dark fitness-focused interface and responsive layouts so the application remains usable across different screen sizes.

The UI focuses on:

* Clean workout cards
* Responsive grids
* Exercise imagery
* Clear typography
* Interactive buttons
* Consistent dark-theme styling
* Mobile-friendly layouts
